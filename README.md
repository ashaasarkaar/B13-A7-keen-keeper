# 🧠 Keen Keeper
Keen Keeper is a simple and modern interaction tracking web application built with Next.js. It help users to communicate their friends through the different media. such as: audio call, text and video call. After communicate later, they can see their communication history with mention time, name and contact-type through an organized timeline.

The Application provides a user friendly interface to manage their friend information and monitoring communication activities.

## 🚀 Technologies Used
The project has built the following technologies that i gave below:

A- **Next.js** –> React framework for building the application
B- **React** –> For building reusable and interactive UI components
C- **Tailwind CSS** –> For styling and responsive layouts
D- **DaisyUI** –> For ready-to-use UI components and theme support
E- **React Icons** –> For interface icons
F- **React Toastify** –> For displaying interaction notifications
G- **Recharts** –> For displaying interaction statistics and charts
H- **JavaScript (ES6)** –> For application logic and functionality

## ✨ Key Features

### 1. 👥 Friend Management

Users can view detailed information about their friends, including:

- Friend name
- Profile picture
- Email address
- Status
- Tags
- Biography
- Personal goals
- Next due date
- Days since last contact

This makes it easier to keep important information about friends organized in one place.

---

### 2. 📞 Interaction Tracking & Timeline

Keen Keeper allows users to record different types of interactions with their friends:

- 📞 Audio Call
- 💬 Text Message
- 📹 Video Call

Each interaction is added to the timeline with the friend's name, interaction type, and time.

The timeline also provides useful controls such as:

- Search interactions by friend name
- Filter interactions by interaction type
- Sort interactions by newest or oldest
- View the complete interaction history

This helps users easily track and review their communication history.

---

### 3. 📊 Interaction Statistics

The application provides a statistics page where users can visualize their interaction history.

It displays the number of:

- Calls
- Text messages
- Video calls

The statistics are presented using interactive charts, making it easier to understand communication patterns at a glance.
